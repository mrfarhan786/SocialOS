# Native platform adaptation

Retrieve the current master and compact workspace context. Read target platform editorial guidance as advice, not as verified algorithm rules. Verify current limits, supported metadata and disclosure requirements from official sources when required.

For each target platform, consider consumption context, opening, pacing, duration, framing, text density, caption/title, CTA, accessibility and discovery role. Do not merely copy or crop a master piece. Keep claims and essential meaning consistent.

Save variants with a stable unique ID, platform, format, hook, script, caption, CTA, title, duration when relevant, disclosures and the exact master_revision. Preserve unrelated variants when saving the complete content object. Use distinct formats for long video and short video.

Never fabricate technical requirements or source dates. Disclosure notes record what still needs checking. A generated publishing package remains an export; the local edition has no publishing tool.
